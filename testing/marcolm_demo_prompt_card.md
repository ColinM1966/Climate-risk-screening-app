# Marcolm Demo Prompt Card

## Opening

This is an early technical prototype of the Sabah Climate Risk Explorer.

It runs locally from our computer today, so you do not need to install anything.

The app summarities climate raster values inside a selected area of interest.

It is not a final decision-making tool and it does not produce an overall risk score.

We are looking for feedback on what is clear, confusing, useful or fragile.

## Main demo

Jambongan → Fire Probability → comparison.

Explain:
- AOI means area of interest.
- The result table summarises raster values inside the AOI.
- Change from baseline is a simple difference, not a risk score.
- The graph shows mean values from the comparison table.

## Optional WBGT demo

Maximum WBGT is a heat-stress indicator.

This layer represents monthly average maximum WBGT, not daily extreme WBGT.
