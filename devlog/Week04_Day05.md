## Freeze rules

After Day 5, no new features should be added before the friendly technical testing unless they are needed to fix a serious blocker.

Allowed changes:
- app does not start;
- main demo fails;
- download fails;
- serious confusing label;
- missing testing files.

Avoid:
- new variables;
- new scenarios;
- new graph types;
- risk scoring;
- layout redesign.

## Day 5 summary
